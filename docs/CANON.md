## 二、圣杯战争：九个人，九骑，一一对应

| 御主 | 从者 | 身份 | 算不算参赛者 |
| --- | --- | --- | --- |
| 江野 | Saber 科比 | 高二（7）班，篮球队替补 | 是 |
| 张远 | Archer 张雪峰 | 复读部，第三次高三 | 是 |
| 吴迪 | Lancer Otto | 高二（3）班，电竞社社长 | 是 |
| 王大力 | Rider 范小勤 | 高三（9）班，家里开五金店 | 是 |
| 邹丽君 | Caster 马保国 | 政治教师，太极社指导老师 | 是 |
| 李嘉豪 | Assassin 周立齐 | 高二（11）班，家里开电瓶车修理店 | 是 |
| 高鹏 | Berserker 虎哥＆刀哥 | 高一（2）班，抱枕 | 是 |
| 赵铁柱 | Ruler 孙笑川 | 教务处主任 | **不是**，裁判 |
| 林小满 | Foreigner 丁真 | 高三（1）班，学生会宣传部长 | **不是**，编外 |

账要这样算：

- **七席参赛者** = 玩家 + 六名 NPC 常规御主（Saber / Archer / Lancer / Rider / Caster / Assassin / Berserker 各一席）。
- **额外两位** = 赵铁柱（Ruler，裁判，先到）+ 林小满（Foreigner，编外，规则外）。
- **从者九骑全部在场**，因为九位御主都在场。没有例外，不需要「谁自己来的」这种补丁。
- **名单上七行**：前六行是已经登记的名字，**第七行留给你**——你在灯灭那一秒才拿到令咒，圣杯还没登记你。
  所以广播说「参赛者七名，已到六名」是对的：六个人登记了，第七个是你。
- **孙笑川**是被念出来的名字，不在名单上。他是 Ruler，赵铁柱的从者。这是第八个名字，也是「多出来的那一个」。

## 四、三个不能写的说法

1. **「6012 人」** —— 换 6000。
2. **「第七位从者，孙笑川」** —— 他是 Ruler，是第九骑、是额外的一骑。写「还有一骑，不在名单上」。
3. **「七个人都在场」和「已到六名」不要写在同一段** —— 两者都对，但一个是「七个席位」，一个是「六个已登记」。写的时候分清楚主语。

## 五、三条额外线（游戏内也要能玩）

除了默认的学生线，还有三条身份线。玩家抽到对应御主卡时，走对应的线：

| 线 | 御主 | 视角 | 这一线独有的东西 |
| --- | --- | --- | --- |
| 教师线 | 邹丽君 | 站在讲台上 | 巡堂、阅卷、家长会主持、处分、被举报 |
| 裁判线 | 赵铁柱 | 监考席 | 排名系统、广播室、扣分、裁决、写名单 |
| 降临者线 | 林小满 | 拍东西的人 | 官方账号、剪辑、流量、被拍的人、门 |

一条线里其它人的命运可以不一样，**每条线的结局本来就不一样**，不必强求每处总数一致。

## 六、时间线小说

- 每条线 5–7 章，4000–7000 字。
- 每条线至少 4 组御主有具体动作（有名有姓、有做的事）。
- 覆盖至少 4 个固定剧情点：序章召唤 / Day3 月考 / Day4 家长会 / Day5 校运会 / Day6 广播 / Day7 凌晨四点。
- 人数按上面第二节的账写：**九个人、九骑、七席、六名已登记**。
- 各线可以有自己的走法：谁死了、谁没来、谁最后补上第七行，都可以不同——但**总数不能自己发明**。

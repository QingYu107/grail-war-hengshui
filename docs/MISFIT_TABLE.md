# 错位召唤 · 定向答题表

> 相性 E 的触发条件是：**一个关键词都没有命中**。这时候圣杯会把你换到池子里分数最低的那一骑——也就是「最反相性」的那位。
> 下面每个组合都是跑出来的、验证过两遍的：**同一个答案永远得到同一位**（平手用答案哈希挑，不随机）。

## 怎么用

15 位字母依次对应第 0 问到第 14 问。第 0 问是身份栏，它决定你能召到谁：

| 第 0 问选 | 身份 | 候选池 |
| --- | --- | --- |
| A / B / C | 学生 | Saber / Archer / Lancer / Rider / Assassin / Berserker |
| D | 老师 | Caster / Ruler |
| E | 学生会或教务处 | Foreigner / Ruler |

所以 Caster 只能用 D 开头，Ruler 和 Foreigner 只能用 E 开头——这不是 bug，是模组里「御主与从者一一对应」。

| **ASSASSIN 周立齐** | A/B/C | `BCABBBDADDCBDDD` | Rider |
| **BERSERKER 虎哥＆刀哥** | A/B/C | `ACBBDCCABAABABD` | Rider |

「本该召到」那一列就是撕裂动画里先出现、然后被换掉的那一位——所以走错位线的时候，你会先看到它，再看到真正来的那位。

## 备注

- 错位之后有三件后果：从者带「暴走」（第一场战斗前要过 POW，没过它会先打最近的一个人）、判定书四周泛红、序章那张召唤卡会先播「本该召到」的那位、再撕开换成它。
- 如果你只是想要某个从者、不想要错位，正常答题就好，别刻意凑这套。
- 表里的组合是**最省事的那一条**，不是唯一一条。同一个从者有很多组答案都能错位到它。

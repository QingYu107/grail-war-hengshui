# 时间线 · 规格（给下一个会话）

> 这是「档案室里的路线小说」功能的完整规格。读完这一份就能开工，不需要翻对话历史。
> 项目背景见 `HANDOFF.md`，文风样本见 `js/data/bonds.js` 和 `js/data/endings.js`。

## 一句话

通关到一半之后，档案馆里能读到 11 条「时间线」——每个结局一条，像 FSN / FZ 那样，
同一个世界、七组人、不同的走法。每条线是一篇小说，群像，有完整的起承转合。

## 为什么这么做

现在结局只有 400–700 字，玩家知道自己"输了"或"赢了"，但不知道**这条路上其他人是怎么过的**。
七组御主在主线里只在随机事件里露一次脸，没有一条线能让他们同时在场、互相牵制。
时间线补的就是这个：把结局从「一句话判决」变成「一本书」。

## 解锁与入口

- **解锁条件**：已见结局 ≥ 6（11 的一半，向上取整）。数据在 `localStorage['grail_archive_v1'].endings`。
- **入口**：封面「档案馆」。现在的档案馆是一个单页模态框（`openArchive()`，约在 `js/ui.js` 300 行），
  要改成两个标签：「结局图鉴」/「时间线」。
- 未解锁时「时间线」标签仍显示，但内容是一行灰字：
  「再走几条路，这里才会打开。」（不要显示具体缺几个，保持悬念）

## 数据结构

新建 `js/data/timeline.js`（数据量大，可以拆成 `timeline_a.js` / `timeline_b.js` 分批加载）：

```js
window.GRAIL_TIMELINE = {
  E1: {
    title: '满绩',                      // 与结局同名
    sub: '第一条线 · 有人许了「让我赢」',   // 一句话说明这条线的分歧点
    cast: ['saber', 'archer', 'ruler'],  // 这条线上有戏的从者（用于小头像）
    chapters: [
      { title: '第一章 · 铃声', text: ['段落', '段落', '段落'] },
      { title: '第二章 · 名单', text: [...] }
    ]
  },
  // E2 … E11
};
```

## 每条线要写什么

### 1. 必须交代公共事件

这些是「固定剧情」——每个玩家都会经历的事。同一条时间线里，它们**必须按这条线的走法重写一遍**，
而不是复述主线原文。至少覆盖下列 4 个：

| 固定剧情 | 在各条线上可以怎么变 |
| --- | --- |
| 序章 · 动员大会与召唤 | 谁在礼堂、谁在楼下、谁根本没来 |
| Day3 月考（三场） | 考场里发生了什么事，谁缺考 |
| Day4 家长会 | 谁家长来了，谁没来，二楼那间屋子谈了什么 |
| Day5 校运会 / 挖掘机 | 那台挖掘机是谁开的、为什么开进来 |
| Day6 广播坏掉 | 广播是谁弄坏的，坏之前念了什么 |
| Day7 凌晨四点 · 倒数牌 | 站到楼下的是几个人 |

### 2. 群像，不是主角独角戏

每条线至少让 4 组御主有具体动作。写法参考：

- **江野**（saber 科比）：替补、肩伤、四点的球场
- **张远**（archer 张雪峰）：第三次高三、替所有人算路
- **吴迪**（lancer Otto）：电竞社、被骂十年
- **王大力**（rider 范小勤）：写字、挖掘机、想上学
- **邹丽君**（caster 马保国）：打拳的女老师、被网暴十年
- **李嘉豪**（assassin 周立齐）：黑口罩、车棚、两辆车
- **高鹏**（berserker 虎哥＆刀哥）：抱枕、被认真问过一个问题
- **赵铁柱**（ruler 孙笑川）：教务处主任 / 裁判，两边身份
- **林小满**（foreigner 丁真）：学校账号、被拍的人

### 3. 结构

- **每条线 5–7 章**，每章 600–1200 字，单线 4000–7000 字。
- 第一章从「这件事是从哪一天开始不对的」切入，不要从序章平铺。
- 最后一章落在结局正文**之前**的那一刻——结局文本本身不用重写，时间线是它的"前传 + 现场"。
- 章与章之间可以插「档案摘录」：一张通知、一段广播稿、一页名单。用 `\[档案\]` 之类的标记，
  数据和渲染各自处理（见下）。

### 4. 文风（和现有文本一致，别跑偏）

- 第二人称或第三人称都行，但**一条线里要统一**。建议第三人称群像（FZ 那种），因为要写别人。
- 短句。具体的物件、时间、数字、动作。不写情绪词，不抒情，不总结道理。
- 对白用「」，短，不超过两句。
- 样本（摘自现有文本，照着这个语感写）：

  > 他把你的橡皮转三圈，停住，放回桌上，正对着桌角。
  >
  > 食堂的汤还是两块钱。王秀英盛汤的时候会多舀半勺，然后停一下，像在想这半勺是给谁的。
  >
  > 那年招办把「已录取」三个字刻成一枚蓝色印章，盖在每份成绩单的右上角。盖了六千次，墨水换了三盒。

- 禁止：感叹号、省略号堆砌、「仿佛/宛如/似乎」堆叠、英文单词、任何总结性收尾。

## UI

### 档案馆改两标签

```
[ 结局图鉴 ] [ 时间线 ]
```

- 图鉴：保持现在的 `ac-grid`。
- 时间线：左侧是 11 条的列表（未解锁显示 `？？？`），右侧是阅读区。
- 手机端：列表收成抽屉，阅读区占满。

### 阅读器

```
┌ 第一章 · 铃声 ──────────────── 1 / 6 ┐
│                                        │
│  正文段落……                            │
│                                        │
│  [ 上一章 ]  [ 目录 ]  [ 下一章 ]      │
└────────────────────────────────────────┘
```

- 进入一条线时，从「上次读到的那一章」继续（记在 `archive.read = { E1: 3 }`）。
- 读完最后一章，记一次「读完」，在列表里给这条线打一个 `✓`。
- 字号跟随设置里的文字速度档位？不需要——阅读器固定 15px/2.05 行高即可。

### 代码接入点

| 位置 | 改什么 |
| --- | --- |
| `js/ui.js` `openArchive()` | 加标签切换，把「时间线」面板塞进去 |
| `js/ui.js` 新增 `openTimeline(eid)` | 阅读器；用 `.modal-layer` + `.modal.wide` 那套样式 |
| `assets/css/ui.css` | `.tl-list` / `.tl-reader` / `.tl-chapter` 三组样式 |
| `index.html` | `<script src="js/data/timeline.js">`，放在 `ui.js` 之前 |
| `archiveRecord()` | 不变；读取时从 `a.endings` 算解锁数 |

## 分阶段做

1. **框架 + 1 条样板线**（E1 满绩）：先把解锁判断、列表、阅读器、进度记录跑通，文本 3000 字。
2. **再做 3 条**（E4 / E8 / E9）：覆盖「断电」「七人齐」「满分」三种完全不同的收场。
3. **剩下 7 条**：可以分包给子代理，但要先给它们第 1 步那条样板作范文。
